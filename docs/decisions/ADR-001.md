# ADR-001: Tier 1 Base Model — LLaMA 3.1 8B vs Mistral 7B
Date: 2026-10-10
Status: Proposed

## Context

Tier 1 is the frozen core of Veena — the base model that provides general reasoning, world knowledge, and language capability. It will be QLoRA fine-tuned once, then locked permanently. The choice of base model determines:

- Maximum context length available to the whole system (Tier 0 context injection, Tier 3 RAG results, tool outputs all fit in this window)
- License terms governing how Veena can be used and distributed
- GGUF conversion quality and Ollama inference performance at 4-bit quantization
- Training infrastructure requirements (bf16 requirement is already specified in ARCHITECTURE.md Section 3.3)

The two candidates are LLaMA 3.1 8B (Meta Community License, 128K context) and Mistral 7B (Apache 2.0, 32K context).

Key factors from ARCHITECTURE.md Section 3.1:

| Factor | LLaMA 3.1 8B | Mistral 7B |
|---|---|---|
| Context window | 128K tokens | 32K tokens |
| License | Community (Meta) | Apache 2.0 |
| Benchmark performance | Marginally higher | Competitive |
| Long-context tasks | Superior | Adequate |
| GGUF / Ollama support | Full | Full |
| QLoRA fine-tuning | Well-documented | Well-documented |

Outstanding questions to resolve before deciding:
1. Does Veena's inference workload (Tier 0 context + Tier 3 RAG + tool output) exceed 32K tokens in practice? Measure in Phase 0 Week 5 mini-integration.
2. Does the Meta Community License restrict the intended use case (personal AI, owner-only deployment)?
3. Is 4-bit quantization quality meaningfully different between the two on Veena's target domains?

## Risks

- **LLaMA 3.1 8B:** Meta Community License has redistribution restrictions. Verify before Phase 1 starts.
- **Mistral 7B:** 32K context may be insufficient once Tier 0 context + Tier 3 RAG + tool output are all injected. A context overflow here cannot be fixed without retraining Tier 1.
- **Either:** QLoRA training at 8B/7B requires A10G or better on SageMaker — verify instance availability and cost before committing.
