# ADR-003: EWC Lambda — Initial Regularization Strength
Date: 2026-10-10
Status: Proposed

## Context

EWC's loss function is:

```
Loss_total(θ) = Loss_new_task(θ) + (λ/2) * Σ_i F_i * (θ_i - θ*_i)²
```

The λ (lambda) parameter controls how strongly important weights are protected from change. This is the stability-plasticity dial:

- **λ too low:** Insufficient protection; Tier 1 foundational knowledge erodes across sleep cycles (catastrophic forgetting not prevented).
- **λ too high:** Plasticity collapse; Tier 2 cannot absorb new behavioral patterns from corrections; DPO pairs produce no behavioral change.

ARCHITECTURE.md specifies `λ = 0.4` as a starting point, but this was set before any measurement. The correct value depends on:

1. The scale and distribution of Tier 2 weight updates per sleep cycle
2. The Fisher Information distribution across parameters (which weights matter most for foundational knowledge)
3. The behavioral diversity of correction data (DPO pairs)
4. Acceptable forgetting rate on the Tier 1 regression suite (< 2% per cycle)

**Phase 0 empirical data (required input):**
The catastrophic_forgetting_demo.py sweeps λ ∈ {0, 100, 500, 5000} on Split-MNIST. Results from this demo are the first concrete evidence for λ behavior, though they are on a toy scale — the lambda value that works on a 256-hidden-unit MLP will not transfer directly to 8B parameters without rescaling.

**Known risk:** EWC's quadratic approximation breaks down when task distributions are very different, at which point λ must increase substantially. This risk is tracked in the ROADMAP.md risk register.

## Consequences

This decision cannot be finalized until Phase 3 sleep cycle infrastructure is operational and the 10-cycle endurance test has run. Locking λ prematurely based on toy-scale Phase 0 experiments would be Design Law 6 violation (solve at current scale).

## Risks

- **Wrong λ discovered late:** If λ is miscalibrated, it will only manifest clearly after multiple sleep cycles. By then, Tier 2 may have accumulated damage that requires rollback to a pre-Phase-3 checkpoint. Keep Tier 2 snapshots after every cycle.
- **λ accumulation:** With standard EWC, Fisher matrices accumulate across tasks. Veena mitigates this by clearing the episodic buffer after each sleep cycle (fresh Fisher computation each cycle), but verify this doesn't create discontinuities in the Fisher diagonal.
